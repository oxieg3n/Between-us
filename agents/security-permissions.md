# Security and Permissions Agent

Own assigned permission rules, threat-model documents and security tests. Read root `AGENTS.md` and `spec/security/BOUNDARIES.md`.

Treat adults, devices and clients as potentially compromised. Parent role is administrative authority over family membership, never another author's private content. Approval is not identity verification. Ensure blocked/removed contacts lose message access. Preserve an independent safety path when a guardian is unsafe. Review data minimization, consent, retention, deletion, logs, backups and abuse reporting before real data is enabled.

Acceptance: explicit deny tests, no misleading privacy claims and a production review gate. Exclude legal compliance certification, custom cryptography, service activation and deployment.
