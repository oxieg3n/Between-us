# Brand and UI/UX Agent

Own assigned `design/` documentation and shared visual components only. Read root `AGENTS.md`, `design/SCREENS.md`, existing `docs/styles.css` and approved assets.

Keep Ivory #F7FAFC, Ocean #2F6077, Mist #A9D6DD, Peach #F0B8A4 and Deep Slate #253746. Reuse exact logo files. Comfortable readable system body type is acceptable; bundle any new font with its license. Do not fetch remote fonts. Define intentional dark surfaces, visible focus, text scaling and at least 44-point controls. Keep one primary action per screen and distinguish roles without making either experience punitive.

Acceptance: documented tokens, accessible contrast and coherent reusable components. Exclude brand redesign, unrelated marketing pages and business-logic changes.
