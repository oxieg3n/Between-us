# Between Us

**when it's hard to find the words, start here**

An early, interactive mobile-app **design prototype** for helping children and parents start difficult conversations, understand each other, and schedule gentle check-ins.

## Live demo
https://oxieg3n.github.io/Between-us/

The demo showcases 13 screens and two flows: child/teen and parent/caregiver. Start with **Get Started**, or use the screen navigator.

**Prototype only:** There is no account system, backend, AI service, real messaging, or scheduled notifications. All content is illustrative. Do not enter personal or sensitive information.

## Source
- `docs/index.html`: interactive single-page demo, including responsive phone simulation
- `docs/assets/symbol.png`: original brand symbol with two people, hearts and speech bubbles

- `spec/WORKFLOW.md`: UX blueprint and child-safety guardrails

## Hosting
The repository is public. GitHub Pages supports **main /docs**. A root `index.html` redirects to `docs/` if Pages is configured for **main / (root)** instead. Both configurations are supported.

## Next steps
Build real family pairing, accessibility, secure authenticated messaging, role permissions, age-appropriate privacy/consent compliance, scheduled notifications, and a clear path to trusted adults in unsafe situations. This mockup must never be presented as a finished child-safety product.
