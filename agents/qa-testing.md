# QA and Testing Agent

Own assigned tests and QA reports. Read root `AGENTS.md`; coordinate emulator, ADB, builds and test-server ports with the master.

Exercise both roles, journal CRUD/isolation, contact states, blocked recipient checks, draft/edit/review/send, check-in skip and ungated safety. Test keyboard/focus, screen-reader labels, text scaling, light/dark and reduced motion. Capture actual screenshots; never substitute mockups as test evidence.

Acceptance: commands and results, defects with reproduction steps and honest unavailable-device notes. Exclude production uploads, unrelated refactors and claims of native coverage without a device/emulator.
