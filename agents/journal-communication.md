# Journal and Communication Agent

Own assigned local rules/domain files and focused unit tests. Read root `AGENTS.md` and `spec/JOURNAL_AND_CIRCLE.md`.

Reflections must be optional, local, dismissible and conversation-focused. Do not echo journal content into a message, classify mental state, diagnose or advise on resolving a situation. Generic trusted-person alternatives are safer than inferring a particular adult is safe. Keep editable starters, response preferences and explicit message review.

Acceptance: deterministic tests for reflection restrictions, no journal transfer, review and recipient gating. Exclude cloud AI, UI rebranding and persistence.
